# localSpace investor data room

One public page for investors: https://linusip.github.io/localSpace-dataroom/

- `content/dataroom.md`: all text, numbers and sources
- `data/`: the same numbers as JSON (hardware, market, funds)
- `tools-src/`: the Python scripts that produced `data/hardware.json` and `data/market.json`, with every assumption written at the top
